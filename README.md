## Project boundaries

Every repository is meant to stand on its own. Where systems connect, the integration boundary should remain visible: interfaces collect and display scoped information, services return bounded responses, and automation or execution layers require deliberate authorization. Private client work and experimental internal repositories are intentionally not listed here.
